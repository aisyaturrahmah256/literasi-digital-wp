## Deskripsi
Website Literasi Digital merupakan proyek pembelajaran berbasis WordPress yang difokuskan pada edukasi masyarakat mengenai literasi digital (Keamanan Data Pribadi, Cek Hoaks, dan Manajemen Jejak Digital). 

## Tujuan
Meningkatkan pemahaman masyarakat mengenai penggunaan teknologi dan internet secara bijak, aman, dan bertanggung jawab.

## Teknologi yang Digunakan
- WordPress
- PHP
- MySQL / MariaDB (XAMPP)
- Elementor & Contact Form 7
- Git & GitHub Desktop

## Fitur Website
- Halaman Beranda
- Publikasi artikel edukasi literasi digital
- Kategori dan Tag artikel
- Gambar unggulan (Featured Image)
- Halaman statis (Tentang Saya & Kontak)

## Cara Menjalankan Website (Lokal)
1. Jalankan aplikasi XAMPP.
2. Aktifkan modul Apache dan MySQL.
3. Simpan folder website ini di dalam direktori `C:\xampp\htdocs\literasi`.
4. Buka phpMyAdmin dan buat database bernama `wp_literasi`.
5. Import file `database.sql` (dari folder `db`) ke dalam database tersebut.
6. Buat file `wp-config.php` secara lokal dan atur konfigurasi database (file ini sengaja tidak disertakan di repositori publik demi keamanan menggunakan `.gitignore`).
7. Buka tautan `http://localhost/literasi` di browser.
